# ALKENE CHEMISTRY (1974 Vintage Retro Simulator)

<!-- MR DOPPIX CREATED BY BEHRUZ GOFFAROV CONDATCT TEL:70 024 94 14, TELEGRAM: @BEHRUZGOFFAROV -->

1974-yilgi klassik interaktiv kimyo tizimlari asosida yaratilgan, terminalda rangli ANSI/ASCII grafikali C tilidagi organik kimyo simulyatori.

## 🚀 Xususiyatlari:
1. **Molekulalar Galereyasi:** Eten, Propen, Cis/Trans But-2-en, 2-Metilpropen, Siklogeksen 2D ASCII modellari.
2. **Kimyoviy Reaksiya Laboratoriyasi:**
   - Gidrogenlanish ($CH_2=CH_2 + H_2 \xrightarrow{Ni} CH_3-CH_3$)
   - Galogenlanish va Bromli suv sinovi ($CH_3-CH=CH_2 + Br_2 \rightarrow CH_3-CHBr-CH_2Br$)
   - Markovnikov qoidasi bo'yicha gidrogalogenlanish
   - Sanoat gidratatsiyasi (Spirt sintezi)
   - Polimerlanish jarayoni ($n CH_2=CH_2 \rightarrow [-CH_2-CH_2-]_n$)
   - Vagner oksidlanish reaksiyasi ($KMnO_4$)
3. **Retro 1974 Chem-Quiz:** Savol-javob va bilimni sinash musobaqasi.
4. **Interaktiv Alken Konstruktori:** Uglerod zanjiri va qo'shbog' o'rnini tanlash, $\sigma$ va $\pi$ bog'lar hisobi, molyar massa kalkulyatori.
